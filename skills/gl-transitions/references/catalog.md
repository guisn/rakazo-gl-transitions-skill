# Quick index — gl-transitions@2.5.0

The official package contains 193 transitions. This is a curated starting point, not the complete catalog. For all transitions, descriptions, tags, parameter types and defaults, authors, source URLs, and supported shader targets, consult the official [full reference](https://cdn.jsdelivr.net/npm/gl-transitions@2.5.0/llms-full.txt) or the [machine-readable catalog](https://cdn.jsdelivr.net/npm/gl-transitions@2.5.0/gl-transitions.json).

Names are case-sensitive PascalCase. Extra textures must be supplied by the host: `DisplacementMap` requires `displacementMap`; `LumaWipe` requires `luma`.
